Import / Export Data

Excel: satu berkas dengan sheet Rekap Cluster-Area, Node, Kabel, Insiden, dan Sambungan Core. CSV dengan cakupan "Semua" diunduh sebagai ZIP (nodes, cables, connections, incidents). Hasil ekspor Node/Kabel bisa diimpor kembali.

Akun Anda tidak punya izin mengimpor data (hanya NOC dan Admin).
Template: Excel (node + kabel) · CSV node / kabel
Kolom tambahan untuk node (opsional): reg_code; PELANGGAN: service, bandwidth_mbps, device_sn, link_type (GPON/PTP); POP: trunk_mbps, trunk_overbook. Nama, kode registrasi, dan SN harus unik; baris yang bentrok ditolak. Kolom kosong tidak menghapus data lama saat mode perbarui.
Akun Anda tidak punya izin mengunggah hasil OTDR (Teknisi, NOC, dan Admin).
